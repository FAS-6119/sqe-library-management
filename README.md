# SQE Library Management System

## Project Description
The SQE Library Management System is a Java-based project designed to manage library books and members.

## Objectives
- Manage book records.
- Manage library members.
- Search for books.
- Support software quality engineering practices through testing and documentation.

## Technologies
- Programming Language: Java
- Version Control: Git
- Repository Hosting: GitHub

## Project Structure
- `src/` — Application source code
- `tests/` — Test cases
- `docs/` — Project documentation
- `screenshots/` — Evidence and screenshots
- `.github/workflows/` — Workflow automation files

## Project Status
The project repository and initial folder structure have been created. Development and testing will be carried out in later tasks.
